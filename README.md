# Fornax Interior — website concept

A multi-page, responsive website concept for Fornax Interior, the Singapore interior design and renovation studio. Built as static HTML/CSS/JavaScript for GitHub Pages; no build step or dependencies are required.

## Pages

- `index.html` — editorial homepage, project slider and ambient film
- `projects.html` — filterable portfolio using public Fornax Instagram work
- `studio.html` — studio point of view and design principles
- `process.html` — consultation-to-completion journey and service list
- `contact.html` — WhatsApp enquiry form and direct contact links

The site includes a custom wordmark, responsive navigation, pointer-based 3D tilt, project filtering, reduced-motion support and a WhatsApp message composer. Enquiry details are only passed to WhatsApp after the visitor submits the form.

## Preview locally

Open `index.html` in a browser or serve this folder with any static web server.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub Pages will publish the site at `https://tumpabhaigamer-cpu.github.io/fornax-interior-demo/`.
