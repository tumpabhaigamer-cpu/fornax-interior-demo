# Fornax Interior — website concept

A responsive, multi-page website concept for Fornax Interior, the Singapore interior design and renovation studio. Built with static HTML, CSS and JavaScript for GitHub Pages. No build step is required.

## Pages

- `index.html` — nine-part editorial homepage with a 3D material study, project gallery, interactive process track, bento service cards, cinematic film and contact footer
- `projects.html` — filterable portfolio of public Fornax Instagram work
- `studio.html` — studio point of view and design principles
- `process.html` — consultation-to-completion journey and services
- `contact.html` — direct contacts and a WhatsApp enquiry composer

The design uses a custom Fornax wordmark, charcoal/alabaster/champagne palette, responsive navigation, pointer-driven 3D interaction, Three.js PBR material viewer with selectable material styles and light control, reduced-motion support, project filtering, scroll reveals and a prepared WhatsApp enquiry. The 3D material viewer falls back to a CSS material study if WebGL or the Three.js CDN is unavailable.

## Preview locally

Open `index.html` in a browser or serve this folder with any static web server.

## Publish with GitHub Pages

The repository is configured to publish from `main` at `/ (root)`: [open the live website](https://tumpabhaigamer-cpu.github.io/fornax-interior-demo/).
