# Fornax Interior — Demo website

A responsive single-page website concept for Fornax Interior, built from public Instagram profile information and recent portfolio imagery. The layout follows a light, minimal editorial direction informed by the Autosend reference on Mobbin.

## Preview

Open `index.html` in a browser, or serve this folder with any static web server. The page has no build step or external runtime dependencies.

## GitHub Pages

The folder is ready to publish as a static GitHub Pages site. After the project is pushed to a GitHub repository, choose **Settings → Pages → Deploy from a branch**, then select `main` and `/ (root)`.

## Included

- Responsive navigation with a mobile menu
- Pointer-based 3D tilt on the hero photograph
- Keyboard-accessible featured-project slider
- Scroll reveal motion with reduced-motion support
- Instagram portfolio, company website, and WhatsApp links
- Nine locally stored images from the public Instagram profile

## Notes

This is a demo concept. The photographs are from Fornax Interior's public Instagram profile. Confirm final project captions, contact numbers, and image-use permissions with the studio before public launch.
